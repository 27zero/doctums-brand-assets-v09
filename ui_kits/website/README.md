# Doctums — Marketing Website UI Kit

An editorial, consulting-grade homepage for Doctums (Higher Education Consulting / EdTech). Recreates the brand's "living editorial document" feel: paper canvas, hairline structure, serif display, Marine-Blue accents, and the warm desaturated + golden→cyan photo treatment.

## Run
Open `index.html`. It loads the design-system bundle (`../../_ds_bundle.js`) and `styles.css`, then mounts the page. Top-nav links scroll; "Talk to us" / "Request a review" jump to the contact band.

## Files
- `index.html` — interactive composition + mount
- `SiteHeader.jsx` — sticky translucent nav with logo + CTA
- `Hero.jsx` — editorial hero with portrait photo + floating Stat
- `Sections.jsx` — `Services`, `Proof` (dark band), `Insights` (cards), `CTA` (form), `SiteFooter`

## Components used
Button, Card, Input, Stat, PhotoFrame from `window.DoctumsDesignSystem_9e6b2a`.

## Notes
Copy follows the brand voice — practitioner-led, specific over vague, no hype. Imagery comes from `assets/imagery`.
