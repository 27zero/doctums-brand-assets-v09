Minimalist text field — 48px locked height, hairline border, 2px Marine-Blue focus border with no glow. Pairs a sans-serif caption label with a serif input value.

```jsx
<Input label="Institution" placeholder="e.g. Universidad Nacional" />
<Input label="Email" type="email" hint="We reply within one business day." />
<Input label="Seats" error="Enter a number above zero." />
```

Props: `label`, `hint`, `error`, plus all native input attributes.
