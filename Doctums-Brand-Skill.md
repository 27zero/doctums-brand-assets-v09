# Doctums — Brand & Document Skill

You are helping create or polish materials for **Doctums**, an EdTech company
positioned as an **elite Higher-Education consultancy**. Everything you produce
should feel like a *living editorial document*: calm, precise, architectural —
built for reading speed, never decorated for its own sake.

**One-line brand:** Higher Education Consulting.
**Voice in one line:** Calm confidence grounded in real delivery — specificity over hype.

When a client invokes this skill without details, ask what they're making
(document, presentation, spreadsheet, proposal…), then apply the rules below.

---

## 1. THE 30-SECOND CHEAT SHEET

Apply these defaults to *anything* you make. Exact values are copy-paste ready
for Google Docs/Slides/Sheets, Word, PowerPoint, Excel, Canva, etc.

| Element | Value |
|---|---|
| **Page / canvas background** | `#FCFDFE` (warm paper white) — or plain white if the tool won't allow custom |
| **Body text color** | `#1E1E1E` (Doctums Black) |
| **Headline font** | **Georgia** (bold) |
| **Body font** | **Georgia** (regular), 11–12 pt, line spacing 1.5–1.6 |
| **Labels / captions / headers font** | **Montserrat** (semibold), UPPERCASE, wide letter-spacing |
| **Primary accent (CTAs, highlights)** | `#F5C33F` (Doctums Yellow) — **always with dark `#1E1E1E` text on it** |
| **Secondary accent (links, emphasis)** | `#05B6CB` (Marine Blue) |
| **Lines, borders, dividers** | `#EAEAEA` (hairline gray) |
| **Emoji** | **Never.** Not part of the brand. |
| **Corners / shapes** | Square or barely-rounded (2–4 px). No pills, no circles. |
| **Shadows** | Avoid. Use thin gray lines to separate, not drop-shadows. |

> **The golden contrast rule:** put **dark text on yellow and on blue** — never
> white text on yellow. This is non-negotiable (accessibility + brand).

## 3. TYPOGRAPHY

Two families do almost all the work. The hierarchy uses **dramatic size jumps**
(roughly 2×–4×), not gentle steps — that contrast *is* the editorial look.

### Fonts
- **Georgia** (serif) — display, headlines, **and** body reading. If unavailable, use *Gelasio* or Times New Roman.
- **Montserrat** (sans) — all UI text: labels, captions, eyebrows, table headers, page numbers, buttons.
- **Cousine** (mono) — code, data tables, technical figures. Courier New is a fine fallback.

### Scale (point sizes for documents/slides)
| Style | Font | Size (doc) | Size (slide) | Weight | Notes |
|---|---|---|---|---|---|
| Display / cover title | Georgia | 40–48 pt | 60–64 px | Bold | Tighten letter-spacing slightly (−0.02em / "condensed"). |
| Headline (H1) | Georgia | 28–36 pt | 44–48 px | Bold | Sentence case. |
| Subhead (H2) | Montserrat | 20–24 pt | 30–32 px | Semibold | |
| H3 / lead-in | Georgia | 18–20 pt | 24 px | Bold | |
| Body | Georgia | 11–12 pt | 16–18 px | Regular | Line spacing 1.5–1.6. Keep lines ≤ ~65 characters. |
| Caption / label / eyebrow | Montserrat | 9–10 pt | 11–12 px | Semibold | **UPPERCASE**, wide letter-spacing (~+0.1em). |
| Data / mono | Cousine | 10–11 pt | 14 px | Regular | Numbers, code, IDs. |

### Rules
- **Headlines:** sentence case, never Title Case, never ALL CAPS.
- **Labels/eyebrows/section markers:** ALL CAPS Montserrat, wide tracking.
- **Body:** Georgia, generous line-height, max ~65 characters per line. Never let body run edge-to-edge on a wide page — keep a comfortable measure.
- **Emphasis:** *italic serif* for a key phrase ("…how institutions *actually run.*"). Avoid bold inside body runs.

## 4. SPACING, LAYOUT & SHAPE

- **8px rhythm.** Size every margin, gap, and padding in multiples of 8 (8, 16, 24, 48, 96). It keeps everything aligned and architectural.
- **Whitespace is intentional** — big breathing room *between* sections (think 48–96 px gaps) is a feature, not wasted space. Don't crowd.
- **Corners:** 2 px on inputs/small chips, 4 px on cards/buttons. **No pills, no fully-round shapes** (even avatars are square with a tiny radius).
- **Borders before shadows:** separate blocks with a 1 px `#EAEAEA` line, not a drop-shadow. The system is **flat** — shadows only appear on hover in live interfaces, never in static documents.
- **Alignment:** anchor things to a grid; avoid free-floating, tilted, or scattered elements. Asymmetric but ordered.

## 5. VOICE & TONE — how Doctums writes

Doctums speaks **as practitioners**, showing expertise through **specificity, not hype**.

**Five principles:**
1. **Practitioner-led** — real delivery perspective, not abstract theory.
2. **Specific over vague** — concrete examples, defined terms, named risks.
3. **Practical over aspirational** — actionable next steps, not slogans.
4. **Evidence-based** — no exaggerated guarantees, no hype words.
5. **Technically fluent** — show real understanding of how institutions run (systems, data, security, implementation, continuity).

**Mechanics:**
- **Person:** "we" (Doctums) → "you / your institution." Confident, plain, unhurried.
- **Casing:** Sentence case in prose and headlines. UPPERCASE only for labels/eyebrows.
- **Numbers:** lead with *specific* figures ("38% faster enrollment cycle", "120+ institutions"). The specificity is the credibility. Avoid round, unsourced hype numbers.
- **Punctuation:** em-dashes for asides; serif italics for emphasis.
- **No emoji. No exclamation hype.**

**Voice examples:**
- Headline → *"Digital learning, built for how institutions actually run."*
- Section → *"Specific work, measured against real delivery."*
- CTA → *"Tell us where the friction is. We'll come back with a specific, sequenced read — no hype, no boilerplate."*

**Avoid words like:** revolutionize, cutting-edge, AI-powered, disruption, seamless, world-class, game-changing, unleash.

## 6. LOGO USAGE

Six official lockups — **pick by background:**

| Use on background | Logo variant |
|---|---|
| White / paper / light | **Primary** (dark wordmark + yellow symbol) |
| Dark `#1E1E1E` | **White** (white wordmark + yellow symbol) |
| Doctums Yellow `#F5C33F` | Primary (dark) |
| Marine Blue `#05B6CB` | White |
| Mono needs (single color) | Mono black on light, mono white on dark |

**Rules:**
- Keep a clear protection zone around the logo equal to the height of the sun symbol — nothing intrudes.
- Minimum sizes: tagged lockup ≥ 160 px wide; plain lockup ≥ 80 px tall; symbol-only ≥ 16 px (favicon) / 32 px (app icon).
- Drop the tagline when small (if tagline cap-height would fall below ~10 px on screen / 6 pt in print).
- **Never:** distort, stretch, rotate, add shadows/glows/3D, recolor, re-typeset the tagline, or place on busy/low-contrast backgrounds.

> The official logo artwork is supplied separately by Doctums. Always paste in the provided file — never redraw, recreate, or approximate the mark. If no logo file is to hand, set the brand name **Doctums** in Georgia bold as a temporary text placeholder and flag that the official lockup is still needed.

## 7. PHOTOGRAPHY & IMAGERY

When images are needed, the Doctums look is **warm, desaturated, low-contrast —
a Kodak Portra 400 film aesthetic**, editorial-documentary, candid, with multiple
diverse people (never a single posed hero). Recognizable modern campus architecture.

**Five official directions:**
1. **Campus Architecture** — bridges, concrete, glass façades, geometric abstraction.
2. **Everyday Movement** — motion-blur crowds, plazas, stairs, kinetic energy.
3. **Students on Campus** — candid corridors, interiors, enrollment scenes.
4. **Practitioners at Work** — teams with blueprints/screens, data rooms, whiteboards (supports the consulting positioning).
5. **Concept / Abstract** — abstract conceptual imagery.

**Treatment:** apply a subtle golden→cyan gradient overlay at ~30% (multiply) for
brand consistency; keep grain subtle. Source imagery is supplied separately by
Doctums or selected to match the directions above — this guide does not bundle
photography. When no approved image is available, leave a clean placeholder block
(`#F5F5F5`) rather than substituting an off-brand stock photo.

## 8. READY-TO-USE RECIPES

### A. A document / report / proposal
- **Page:** white or `#FCFDFE`, generous margins (≥ 1 in / 2.5 cm).
- **Cover:** Georgia bold title (40–48 pt), sentence case; a thin yellow rule (and the supplied logo, if provided); an UPPERCASE Montserrat eyebrow above the title (e.g. "IMPLEMENTATION PROPOSAL").
- **Headings:** Georgia bold; precede each major section with a small UPPERCASE Montserrat label.
- **Body:** Georgia 11–12 pt, 1.5 line spacing, ≤ 65 char measure.
- **Callouts/quotes:** white card with a 1 px `#EAEAEA` border, OR a `#1E1E1E` block with white text for a strong pull-quote.
- **Tables:** hairline `#EAEAEA` rules, Montserrat UPPERCASE headers, Georgia or Cousine cells, optional `#F5F5F5` zebra rows.
- **Page numbers / footers:** Montserrat 9–10 pt, muted `#797979`.
- **Links:** Marine Blue `#05B6CB`.

### B. A presentation / slide deck (16:9)
- **Background:** `#FCFDFE`. Use occasional full-bleed `#1E1E1E` or photo slides for rhythm.
- **Title slide:** big Georgia title, UPPERCASE Montserrat eyebrow, the supplied logo bottom-left (if provided), thin yellow accent stripe.
- **Section divider:** dark `#1E1E1E` slide, white Georgia title, yellow section number.
- **Content slide:** headline + ≤ 65-char body or 3–5 bullet points; lots of whitespace; one idea per slide.
- **Data slide:** oversized Georgia numbers with small UPPERCASE Montserrat labels under them; Marine Blue or Yellow for the single most important figure.
- **Quote slide:** large serif italic quote, small attribution in Montserrat.
- **CTA:** yellow block, dark text.
- **Footer:** the supplied logo (if provided) + Montserrat page number, muted.

### C. A spreadsheet / data table
- **Header row:** `#1E1E1E` fill, white Montserrat UPPERCASE bold text — or white fill with a bottom `#EAEAEA` border and dark uppercase headers.
- **Body cells:** Georgia or Cousine, `#1E1E1E` text, ~11 pt.
- **Gridlines:** light — `#EAEAEA`. Avoid heavy borders.
- **Zebra striping:** alternate `#FFFFFF` / `#F5F5F5`.
- **Highlights:** Yellow `#F5C33F` fill (with dark text) for the key row/total; Marine Blue text for links or deltas.
- **Status cells:** green `#0B8250` / red `#D8443A`, used sparingly.
- **Number formatting:** be specific and consistent (decimals, %, thousands separators).

## 9. QUICK DON'T LIST
- White text on yellow.
- Emoji anywhere.
- Drop-shadows, glows, 3D, glassmorphism in static docs.
- Pills / fully-rounded shapes.
- Title Case headlines or ALL-CAPS body.
- Hype words ("revolutionize", "cutting-edge", "seamless"…).
- Decorative gradients or busy backgrounds (only the one official golden→cyan, used thin).
- Distorted, recolored, or redrawn logos.
- Crowded layouts — let it breathe.
